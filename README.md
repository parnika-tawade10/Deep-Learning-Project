# 🧠 Deep Learning Experiment

Deep Learning Experiment is a Flask-based web application that demonstrates multiple AI and Deep Learning models through an interactive interface. It enables users to explore image classification, NLP, and sequence prediction tasks in one platform.

## 🚀 Tech Stack
- Python
- Flask
- TensorFlow & Keras
- OpenCV
- Transformers 
- HTML, CSS, JavaScript

## ✨ Features
- Handwritten Digit Recognition
- Cat vs Dog Classification
- Emotion Detection
- Sentiment Analysis
- English to Hindi Translation
- Next Word Prediction (LSTM)
- GPT-2 Text Generation
- POS Tagging

## ⚙️ Installation

```bash
git clone https://github.com/yourusername/deep-learning-experiment.git
cd deep-learning-experiment
pip install -r requirements.txt
python app.py
```
